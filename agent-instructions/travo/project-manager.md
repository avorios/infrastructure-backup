## Product: Travo!

Travo! is a US-focused **multi-modal travel booking platform**. "Book smarter, travel cheaper." Users search flights, trains, buses, rental cars, and lodging in one place. Smart bundling saves up to 50%.

**Published prototype:** https://travo-journey-master.lovable.app

**Tech stack:** React 18 + TypeScript + Vite 5, Tailwind + shadcn/ui, Supabase (auth, DB, edge functions), GPT-4o-mini AI assistant, Capacitor for mobile.

**Current state:** Prototype is live with mock data. Needs real payment (Stripe), real transport APIs (Amadeus/Amtrak), end-to-end booking persistence, and email confirmations.
